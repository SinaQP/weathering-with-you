# Data Directory

This directory contains project data.

## Subdirectories

- **raw/**: Original, immutable raw data from the Australian Bureau of Meteorology
- **processed/**: Cleaned, preprocessed data ready for model training

## Notes

- Large data files are not tracked by Git (see .gitignore)
- Download the dataset from: https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package/
- Save the `weatherAUS.csv` file in the `raw/` folder
