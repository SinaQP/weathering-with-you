# Contributing

This is a final exam project for a Machine Learning certification. While it's shared publicly, contributions are limited to:

- Bug reports or issues you find
- Suggestions for improvements
- Questions or discussions

To contribute:

1. Open an issue describing the problem or suggestion
2. For code contributions, fork and create a pull request

## Note

This project represents my own work for my ML certification exam, so major changes won't be accepted. However, I'm open to feedback and discussion!
